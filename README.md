# WaffleKraken.github.io

Source for [wafflekraken.dev](https://wafflekraken.dev), hosted on GitHub Pages.

It's plain HTML and CSS with no build step. Edit `index.html` and push to `main`, and the site updates within a minute or two.

`CNAME` holds the custom domain. Don't delete it, or GitHub Pages will drop the domain.
